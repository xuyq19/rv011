# Linux 0.11 for RISC-V — 功能与压力测试指南

## 1. 启动

```sh
cd /home/lucas/rv011/linux-0.11
make -j8
make run
```

启动到 `sh#` 后，直接在提示符输入测试程序名即可。所有测试程序位于
rootfs 的 `/bin` 下（`ls /bin` 可查看）。

## 2. 功能测试

| 命令 | 覆盖内容 | 预期结尾 |
|---|---|---|
| `t_up` | 极简 printf（%d/%s/%x）回归 | `done` |
| `t_fork` | fork/exec/wait、退出码、pid/ppid | `fork test done` |
| `t_cow` | 写时复制数据隔离、brk 堆增长+fork | `cow: heap intact = yes` |
| `t_fs` | 10KB 文件读写/lseek/硬链接/unlink/mkdir/chdir/stat/access/dup2/fcntl | `fs test passed` |
| `t_pipe` | 管道 4KB 传输 + 子进程应答 | `pipe test passed` |
| `t_sig` | SIGALRM handler+restorer、kill/SIGKILL、信号屏蔽 | `sig test passed` |

示例：

```
sh# t_fork
fork test pid=3 ppid=2
child 3 pid=7 ppid=3
...
fork test done
```

出现 `FAILED` 或内核 panic 即视为失败。

## 3. 压力测试

### t_sched — 调度压力

```
sh# t_sched
```

同时生成 12 个忙碌子进程（各 30 万次循环），验证：

- 所有子进程都拿到 CPU 时间并正常结束；
- 退出码正确（100+i 左移 8 位，如 `6400`/`6f00`）；
- 父进程 wait 回收无遗漏。

### t_stress — 综合压力（推荐做长时间 soak）

```
sh# t_stress
```

五阶段：

| 阶段 | 内容 |
|---|---|
| 1 | 连续 20 次 fork + exec `/bin/t_hello` 并回收 |
| 2 | 8 个并发子进程各自创建/写入/读回/删除 3 个文件 |
| 3 | brk 堆压力：逐页增长到 30000 页（约 120MB）后收缩，再 fork 验证系统仍可用 |
| 4 | 双管道 100 次 512 字节 ping-pong（父子双向） |
| 5 | 8 路 COW 写冲突后验证父进程数据完整 |

长时间 soak 建议连续多轮（shell 已支持多行粘贴）：

```
sh# t_stress
sh# t_stress
sh# t_stress
```

每轮约 30 秒，pids 会持续增长，无崩溃/卡死/输出丢失即通过。

## 4. Shell 交互测试

内置命令：`cd`、`pwd`、`echo`、`ls`、`exit`。

```
sh# ls
bin  dev
sh# cd bin
sh# ls
sh  hello  t_hello  t_fork  ...
sh# cd ..
sh# echo hello world
hello world
sh# exit
```

可验证：逐字符输入（无卡死）、退格（DEL 与 BS 均可，屏幕应擦除字符）、
多行粘贴、命令参数传递（`t_up` 等无参程序不受影响）。

## 5. 常见问题排查

| 现象 | 排查方向 |
|---|---|
| 启动停在 `Free mem:` 之后 | 检查是否改了 trap.S/调度；重新 `make clean && make` |
| 输出乱码/丢字符 | 控制台 cli/sti 嵌套；连续输出压测 |
| 每行只打一个字符 | 用户态 ecall 是否声明了 t0/t1 clobber |
| `alarm` 不触发 | `jiffies++` 是否在定时器路径 |
| 退格不擦字 | termios 是否含 ECHOE |
| FS 报 ENOSPC/双释放 | 位图语义（clear_bit 返回值、mount_root 只读统计） |

## 6. 自动化建议

可把 QEMU 的串口接到管道做自动化：`-serial pipe:/tmp/qp` 或
`(sleep 4; printf 't_stress\n'; sleep 35; printf 'exit\n') | qemu ... -serial stdio`，
然后对输出做关键字断言（`passed` 出现、`FAILED`/`panic` 不出现）。
